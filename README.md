# 📊 Análisis de Ventas de Bike Store (Bike Store Relational Analytics)

---

## 🎯 Objetivo del Proyecto

Diseñar e implementar un proyecto analítico completo de extremo a extremo utilizando la base de datos de muestras de bicicletas (Bike Store), abarcando la ingeniería de datos en SQL para la unión de múltiples tablas relacionales ($1:N$), la aplicación de fórmulas matemáticas de descuento y la creación de una VIEW optimizada, culminando en un panel visual ejecutivo (dashboard) interactivo en Power BI Desktop para un portafolio profesional.

## 🛠 Herramientas UtilizadasSQL (SQLite / DBeaver):

Gestión de bases de datos relacionales, uniones complejas mediante múltiples JOIN (orders, customers, stores, order_items, products), y creación de vistas (vw_vendas_detalhadas) para el cálculo automatizado de ingresos netos a nivel de fila.

Power BI Desktop: Importación de datos limpios vía CSV, diseño de interfaz gráfica (UI/UX) personalizada con tarjetas de métricas, gráficos de líneas temporales de ventas por tienda, filtros interactivos (slicers) y gráficos circulares de distribución de descuentos.

Git & GitHub: Control de versiones y documentación del portafolio profesional.

---

## 💡 Principales Insights

Métricas Financieras Generales: La facturación total auditada (Total Revenue) alcanzó los $7,689K, con un volumen total de 7K unidades comercializadas y un promedio general destacado por transacción.

Rendimiento por Tienda: El panel permite comparar de forma dinámica el rendimiento de las tres localizaciones de la red: Baldwin Bikes, Rowlett Bikes y Santa Cruz Bikes.

Estrategia de Descuentos: Análisis detallado de la aplicación de políticas comerciales, mostrando la proporción exacta de ventas distribuidas por franjas de descuento (0.05, 0.07, 0.10 y 0.20).

Tendencia Temporal: La evolución mensualizada entre enero de 2016 y julio de 2018 revela picos estacionales significativos de demanda, destacando el fuerte crecimiento registrado a principios de 2018 antes de la estabilización del periodo.
